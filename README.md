# 证件水印

给身份证、银行卡等证件照片加上防盗用水印的纯前端小工具。

**图片仅在本地浏览器处理，绝不上传服务器** —— 打开网页即用，也可保存 `index.html` 后离线使用。

## 特性

- 🔒 纯前端、零依赖、零上传，隐私安全
- 📝 自定义水印文字、颜色、不透明度、大小、间隔、字体
- 📱 自动按 EXIF 方向纠正手机竖拍照片
- 💾 一键保存成 PNG，设置自动记忆（localStorage）

## 使用

在线打开 `index.html`，或直接把文件下载到本地双击打开。

1. 选择证件图片
2. 填写水印文字（如「仅供XX实名认证使用」）并调整样式
3. 点「保存图片」下载
